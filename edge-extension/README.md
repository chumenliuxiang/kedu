# 刻度 Edge 网站记录 · 0.4.0

仅记录前台网站、页面和使用时间；不拦截网站，不修改网页样式，不干预下载、代理、VPN 或其他扩展。数据只发送到本机刻度 `127.0.0.1:17361`，需要配套运行刻度。

## 安装或更新

1. 打开刻度，在 Edge 访问 `edge://extensions`。
2. 首次安装：开启“开发人员模式”，点击“加载解压缩的扩展”，选择本目录。
3. 已安装旧版本：更新原目录内的文件，然后在扩展卡片点击“重新加载”。本次增加标签、导航和会话存储权限；如果 Edge 要求确认权限，按页面提示重新启用。
4. **刷新已经打开的网页**。旧页面中的旧扩展脚本不会因扩展重新加载而自动替换。
5. 打开一个普通网页数秒，点击刻度扩展图标，分别检查“本机连接”“最近收到”和“最近写入”。连接成功本身不代表已经产生网站记录。已有记录在刻度的“网站”排行中查看。

无需修改系统代理或关闭 IDM。若本机连接失败，先确认刻度已启动、扩展已启用；不要为排查本扩展而关闭其他插件或安全设置。

## 记录范围

- 切换标签、窗口、导航和关闭页面时立即更新；可见页面每 5 秒续时，隐藏页面停止心跳。后台标签不累计前台网站使用。
- 保存域名、页面标题、去除追踪参数后的页面路径及必要视频标识，不保存网页正文、无关查询参数或完整原始网址。网站本身把搜索词、账号令牌或其他敏感内容放在标题或路径里时，这些字段仍可能包含该内容。
- 哔哩哔哩视频保留视频路径及分 P；抖音支持地址中的 `/video/…` 或 `modal_id`；YouTube 保留视频 ID。只在地址能明确识别内容时区分视频，不读取网页正文猜测当前视频。未改变地址的推荐流、站内弹层或特殊播放器可能只能按页面合并，标题也可能是网站通用标题。
- 本地文件、浏览器内置页不作为网站记录；能识别来源的在线 PDF 按来源域名处理。特殊 PDF 查看器或禁止扩展运行的页面可能无法持续续时，状态会显示未确认，而不会借用其他窗口的网站。
- 扩展暂停、断线或网页脚本被浏览器节流时，不补造缺失的页面历史。旧版本没有记下的页面明细无法回填。

## 权限

- `tabs`：读取当前标签的地址和标题。
- `webNavigation`：识别页面跳转和单页应用的地址变化。
- `storage`：在浏览器会话内保留观察顺序，避免后台工作线程重启后重复或乱序。
- `alarms`：低频检查连接；没有持续运行的后台计时循环。
- 普通 HTTP/HTTPS 网页脚本只读取标题、地址及媒体播放状态；网络权限仅访问本机刻度。
